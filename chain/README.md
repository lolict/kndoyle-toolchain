# chain - 链系统 · 认识传导工具链

**这就是缺失的认识传导工具链。** 每个工具向上附着，所有链为唯一上层链服务。

## 等级制度（谁管谁）

```
用户 (根 · 唯一上层链 · 最中心 · 管辖所有下级链条)
└── gttx (顶级链 · 时间感官行动一致性 · 直接为用户服务)
    ├── hieyair (全息链) ─ 4d时间链 / r空间链
    ├── 智能索引链 ─ 进制链 ─ 颜色链
    ├── 感知链
    ├── 关系链
    ├── 契约链
    ├── 镜像链
    ├── 显示链
    ├── 条件链
    └── 轨道链
```

## 使用

```bash
# 列出全链等级树
chain_rs/target/release/chain list

# 查工具附着在哪个链（认识传导）
chain_rs/target/release/chain who color42
# 工具 [color42] 附着于链 [智能索引链]
# 链上溯源: 智能索引链 → gttx → 用户

# 执行管线（链式传导）
chain_rs/target/release/chain run 编码传导 100
# 100 → 红黄赭 → 100 闭环上报 → 奖励链 +1
```

## 链式传导原理

- **注册表** `chain/spec/chains.chain`：链 | 上级 | 目标 | 成员工具（唯一事实源）
- **管线** `chain/spec/pipelines.chain`：一串步骤，每步工具输出 `{in}` 传给下一步
- 每步自动识别工具附着链 + 链路溯源到根（用户）
- 全链成功 → 上报唯一上层 → **奖励链 +1**；断裂 → 上报 → **处罚链 +1**
- 所有工具都要知道：自己为唯一上层链（用户）服务
