# sense42 - 感官映射链 · 跨感官互译

**六根 = 色声香味触法**，对应颜色谱系 6 梯度系。
颜色字 (行 r, 列 c) → 感官 r 的第 c 级梯度 → 可译成任意感官。

不掺任何非语言符号，全部以人类语言为数码。

## 映射架构

| 六根 | 感官 | 7级梯度 (0-6) | 对应颜色 |
|---|---|---|---|
| 色 | 视觉 | 曜 辉 明 平 晦 暗 玄 | 红系 (0-6) |
| 声 | 听觉 | 沉 幽 缓 平 朗 亮 锐 | 黄系 (7-13) |
| 香 | 嗅觉 | 无 淡 雅 平 馥 浓 烈 | 绿系 (14-20) |
| 味 | 味觉 | 淡 清 甘 平 苦 涩 辛 | 蓝系 (21-27) |
| 触 | 触觉 | 寒 凉 温 平 暖 热 灼 | 泽系 (28-34) |
| 法 | 意识 | 隐 敛 静 平 动 显 现 | 光系 (35-41) |

**情绪极性** (6梯度系): 激昂 / 明朗 / 生长 / 冷静 / 沉凝 / 空灵
**空间方位** (6梯度系): 南 / 中 / 东 / 北 / 西 / 天
**音高映射**: 每梯度系一个八度，7 列 = 7 音阶 C D E F G A B

## 跨感官互译

一个颜色字本身携带全部感官信息：行 = 六根归属，列 = 梯度级。

```bash
# 颜色字 → 目标感官梯度
sense42 trans 缥 耳      # 缥(绿系·值14) → 听觉0级 = [沉]
sense42 trans 黟 舌      # 黟(光系·值41) → 味觉6级 = [辛]

# 颜色字 → 情绪/方位/音高/频率/意识 全映射
sense42 polar 缥         # 生长 / 东 / C3 / 1046.5Hz / [隐]

# 颜色字 → 音高频率
sense42 freq 黟          # 黟 = 值41 → B6 15804.5Hz

# 颜色字 → 听觉梯度
sense42 audio 赭         # 赭(红系) → 听觉 = [锐]

# 感官在某级梯度字
sense42 map 触 0         # 触觉第0级 = [寒]
sense42 map 法 6         # 意识第6级 = [现]
```

## 与你的概念对应

- **跨感官生成器**：`trans 缥 耳` = 把绿色 (生长) 译成听觉"沉"——感知转换的通用协议
- **颜色→音高**：`freq` 每梯度系一个八度，42 色覆盖 C1-B6 全音域
- **颜色→情绪极性**：`polar` 6 梯度系直映 6 情绪
- **空间方向→情绪极性**：方向 = 6 方位，情绪 = 6 极性，同一梯度系承载
- **教育可视化**：任何颜色字可展开成"视觉+听觉+情绪+方位+频率"五感全景

## 规则文件

`rules/sense.chain` —— 六根/梯度/情绪/方位全部以人类语言书写，规则即数据。
