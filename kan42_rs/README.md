# kan42 - 感知进制链 · 全量化辅助状态变化

**身份互换**：多谱系串联为层级化组织，任一谱系的字可换到另两个谱系。
不掺任何非语言符号，全部以人类语言为数码。

## 三级谱系（层级化组织）

| 谱系 | 进制 | 构成 | 属性 |
|---|---|---|---|
| 音韵 | 2760 | 声母23 × 韵母24 × 声调5 | 最宽单位 |
| 颜色 | 42 | 6梯度系 × 7色 | 中单位 |
| 时间 | 60 | 天干10 × 地支12 = 60甲子 | 窄单位/相位 |

**层级**：时间(窄/相位) 管 颜色(中) 管 音韵(宽) —— 加法管理乘法，权力链条。

## 关系算子（身份互换 · 异置互换）

- **公约数 = 中心**（正交点/静态不变/男人）：全谱系共享的不变量
  `gcd(42, 60, 2760) = 6`
- **公倍数 = 边界**（镜像对偶/曲线/女人）：包裹中心的周期
  `lcm(42, 60, 2760) = 19320` —— 全谱系回归同一中心的周期
- **镜像对偶**：值 v ↔ 进制-1-v，对称轴 = (进制-1)/2
- **静态固化**：符号不变 → 层级关系不变 → 可测量性不变（预加载字典稳定）

## 使用

```bash
# 颜色字定位
kan42 color 缥        # 缥 = 行3[绿系] 列1 值14

# 音节 → (声母,韵母,声调)
kan42 yinyun ma阴平

# 甲子查询
kan42 jiazi 甲子      # 甲子 = 天干0 地支0 值0

# 镜像对偶
kan42 xh 颜色 0       # 0 ↔ 41 (对称轴 20.5)

# 公约数(中心) / 公倍数(周期)
kan42 gcd             # gcd(42,60,2760) = 6
kan42 lcm             # lcm(42,60,2760) = 19320

# 梯度归属
kan42 gd 颜色 14      # 值14 → 行3[绿系] 列1 缥
kan42 gd 时间 0       # 值0 → 甲子
```

## 与你的概念对应

- **身份互换**：字 ∈ 任一谱系 → 换到另两谱系（异置互换）
- **公约数/公倍数**：中心男人 = 公约数（静态不变）；边界女人 = 公倍数（镜像对偶）
- **正交线正交点**：gcd 中心；**周长**：lcm 周期
- **预加载字典**：符号不变 → 静态固化 → 可测量性不变
