# colorcode - 汉字本体颜色编码（三维进制编码）

**每个汉字本身就是一个数码**，不做代号替换。两套 6 行 × 7 列 = 42 字表，
作为 42 进制数码集使用。

## 两套表

### 第一套 · 颜色表（无梯度）

| 行 | 字 |
|---|---|
| 1 | 红 橙 黄 绿 青 蓝 紫 |
| 2 | 褐 棕 黑 靛 粉 彩 白 |
| 3 | 朱 绛 赭 丹 彤 缃 黛 |
| 4 | 翠 碧 缥 素 银 金 灰 |
| 5 | 玉 琅 晶 璃 珀 瑙 璧 |
| 6 | 曦 辉 霓 旖 靡 暝 黟 |

### 第二套 · 韵律表（带梯度系）

| 行 | 梯度 | 字 |
|---|---|---|
| 1 | 赤基 | 妃 粉 彤 赤 棕 绛 赭 |
| 2 | 黄系·光 | 缃 金 黄 褐 黧 乌 黑 |
| 3 | 绿系·生 | 缥 翠 绿 青 苍 黛 玄 |
| 4 | 蓝系·冷 | 素 银 蓝 紫 靛 绀 黯 |
| 5 | 泽系·石 | 玉 琅 晶 璃 珀 瑙 璧 |
| 6 | 光系·韵 | 曦 辉 霓 旖 靡 暝 黟 |

## 三维进制编码原理

- **一维 = 一汉字位置**：`行*7 + 列` → 值 0..41，一个字就是一个数码
- **二维坐标**：(行, 列) ∈ 6×7 = 42 位，每字一坐标
- **三维进制**：默认固定 3 个汉字表示一个数，42 进制
  `value = d2*42² + d1*42 + d0`，范围 0 .. 42³-1 = 74087
- 支持任意位数编码，多字序列即可表示更大范围

## 使用

```bash
python3 color42.py list                 # 列出两套表
python3 color42.py v 红                 # 字→值: 红 = 0
python3 color42.py c 41 韵律            # 值→字: 41 = 黟
python3 color42.py e 100 颜色 3         # 数值→三维编码: 红黄赭
python3 color42.py d 红黄赭             # 字串→数值: 100
python3 color42.py p 缥 韵律            # 字→坐标: (行3,列1)
python3 color42.py g 玄                 # 字→梯度系: 绿系·生
```

## 设计约定

- **字就是编码**：汉字是本体数码，不用 a/b/0/1 等代号替换
- **两套适配**：颜色表无梯度（纯色相），韵律表有梯度（光/生/冷/石/韵），
  可按人类习惯选择用哪套
- **扩展**：未来可再分其他范畴（如材质/方位/情绪），在 `TABLES` 中追加即可
