# lang42 - 声韵调层级进制 · 以人类语言为单位的进制

**进制必须以排列发生，以人类的声母/韵母/声调为数码单位，不掺任何非语言符号**
（不用 + - × ÷ 等符号代表发音，那是跟随别人设置的规则）。

## 三级数码单位

| 层级 | 单位 | 数量 | 属性 |
|---|---|---|---|
| 声母 | 窄单位（最窄量化） | 23 | b p m f d t n l g k h j q x zh ch sh r z c s y w |
| 韵母 | 宽单位（最长符号量） | 24 | a o e i u ü ai ei ui ao ou iu ie üe er an en in un ün ang eng ing ong |
| 声调 | 相位单位 | 5 | 阴平 阳平 上声 去声 轻声 |

**音节 = 声母 + 韵母 + 声调 = 共同体（字）** = 23 × 24 × 5 = **2760 个音节**
= 语言全方位覆盖。每音节是一个共同体（字），声韵调合一。

## 组织化建制（层级化 · 一维时间串联）

- **层级化**：声母（窄）管 韵母（宽）—— 加法管理乘法，权力链条
- **一维时间串联**：声母在时间上先于韵母，声调为相位
- **公约折叠**：2760 = 23 × 24 × 5，按因子拆分层级，可折叠的层级关系
- **四维封装**：以音节为共同体（字），音节串封装出更高层级总量
- **异置互换**：每个符号音态不同、发音不同，才能统计区分身份模态

## 使用

```bash
# 音节 → 三维坐标
lang42 jie ma阴平
# 音节 ma阴平 → (声母2, 韵母0, 声调0)  值=240  层链: m(窄) → a(宽) → 阴平(相位)

# 数值 → 音节编码 (四音节 = 2760^3 空间)
lang42 e 100
# 100 → ba阴平.ba阴平.ba阴平.bang阴平

# 音节串 → 数值
lang42 d ba阴平.ba阳平.ma阳平.ta阳平
# = 8283361

# 公约折叠: 因数分解找层级
lang42 fold 2760
# 2760 = 2 × 2 × 2 × 3 × 5 × 23
```

## 规则文件

`rules/yinyun.chain` —— 声母/韵母/声调全部以人类语言书写，规则即数据，可扩展。
未来可追加：天干地支（60甲子）、二十八星宿、十二生肖、部首笔画、五笔布局等
更广生态的进制化，统一挂到链系统。

## 为什么不是 16 进制

16 进制是数学工具（git 用它做 commit 标识），**不是你的编码架构**。
你的编码以人类语言为数码，任何非语言符号都不进入进制。
